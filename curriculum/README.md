# 금산초 교육과정 플래너

월별 학사일정 편집, 수업일수 계산, 교과 시수 배정, 연간 차시 초안 생성을 위한 브라우저 앱입니다.

## 실행

GitHub Pages 배포 후 저장소 사이트 주소의 `/curriculum/` 경로로 접속하세요. 로컬에서는 이 폴더의 세 파일을 함께 다운로드한 뒤 `index.html`을 여세요. 빌드나 API 키가 필요하지 않습니다.

## 주요 기능

- 월별·학년도 전체 달력, 일정 등록 및 드래그 이동
- 방학·휴업일·체험학습 및 대상 학년 지정
- 학기별·요일별 수업일수 자동 계산
- 학년별 시수 배정과 연간 차시 초안, CSV 출력
- 법정·대체공휴일의 빨간색 표시, 수업일수 자동 제외
- 변경 취소, JSON 백업 및 복원

## 데이터 저장

기록은 현재 브라우저의 localStorage에 저장됩니다. GitHub 저장소로 자동 전송되지 않으며 여러 기기 사이에 동기화되지 않습니다. 백업 파일로 옮길 수 있습니다. 기존 Sites 주소와 GitHub Pages 주소는 저장 공간이 다르므로 Sites 앱에서 **백업 저장** 후 새 주소에서 **불러오기**를 사용하세요. 학생 개인정보가 포함된 백업 파일은 저장소에 올리지 마세요.

## 공휴일 기준

2026-11-16 확인한 공휴일 규정에 따라 2025~2035학년도에 반영합니다. 노동절·제헌절은 2026년부터 적용합니다. 2025~2028년 음력 주요 날짜는 한국천문연구원 자료와 대조했습니다. 이후 날짜는 현행 규정 및 한국 음력 계산에 따른 예상이며 공식 연도별 발표를 대신하지 않습니다. 추가 임시공휴일·선거일 및 법령 변경은 확인 후 반영해야 합니다. 공휴일과 방학이 겹쳐도 하루만 제외합니다.

- [공휴일 규정](https://www.law.go.kr/법령/관공서의공휴일에관한규정)
- [한국천문연구원 월력요항](https://astro.kasi.re.kr/kor/life/post/almanac?search_year=2027)

기본 방학·체험학습 일정은 예시입니다. 실제 학교 학사일정과 기준 시수에 맞게 수정하세요.
